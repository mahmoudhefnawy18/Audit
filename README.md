# Gynae Analgesia Audit v3

Temporary, non-identifiable, mobile-first audit collection app.

## v3 changes
- Fixed Delete for saved cases.
- Case numbering starts at 1.
- Chooses and retains one random Monday-Sunday audit week from the preceding 3 months.
- New cases default to that Monday.
- Date and time are separate inputs throughout the form.
- Time inputs default to 09:00 and remain editable.
- Protocol observation scheduling retained.
- Local storage, Excel export, JSON backup/import retained.

Upload all files to the root of the GitHub Pages repository and commit. No database is required.
